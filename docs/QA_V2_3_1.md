# QA V2.3.1 — 10 Oktober 2026 UTC

Penyempurnaan terarah dari V2.3, tanpa perubahan konten, palet, susunan bagian, sumber gambar, atau konfigurasi backend.

## Pemeriksaan otomatis

- TypeScript dan production build/prerender diperiksa lewat `npm run check` dan `npm run build`.
- `npm test`: 24 tes, terdiri dari 17 tes chat/data/rating/Lua sebelumnya dan 7 tes scene/interaksi baru.
- Tes scene memakai `PerspectiveCamera` dan `Vector3` Three.js sebenarnya, tanpa membuat renderer atau browser: jarak inertia pada 30/60/120 update per detik, horizontal vs vertical gesture, fit perspective pada ukuran stage mobile/desktop, proyeksi kamera berputar, ukuran hit area di kedalaman yang sama, titik di belakang kamera/di luar stage, dan pemisahan status renderer dari tipe scene.
- Konten dan byte aset dibandingkan dengan ZIP V2.3 sebelumnya. PROJECTS, JOURNEY_STEPS, ECOSYSTEM, PEOPLE, COMMUNITIES, shared/profile.json, serta foto/avatar asli tetap sama.
- Aset lokal dan 35 SVG diperiksa. Metadata tetap satu H1; seluruh 16 karya dan 19 tools ada di HTML static.
- Integritas ZIP source + dist diperiksa. Kredensial Upstash tetap hanya pada server; tidak ada env rahasia dalam ZIP.

Log final: `build-output-v2.3.1.txt`, `test-output-v2.3.1.txt`, `static-validation-v2.3.1.json`.

## Temuan yang diperbaiki

Registry V2.3 mengumpulkan semua `[data-spatial]` dari document, sehingga status ready pada HTML dapat diperlakukan sebagai scene kosong dan memperoleh kelas spatial-ready. Selector CSS lama kemudian dapat menyembunyikan fallback di seluruh halaman. Registry sekarang dibatasi ke React root dan tipe scene yang valid; CSS fallback hanya berlaku pada anak langsung stage yang sudah dirender.

Inertia sebelumnya ditambah per frame, sehingga laju putaran berbeda antar frekuensi render. Integrasi eksponensial sekarang menggunakan detik dan teruji memberi jarak putaran sama. Target klik memakai camera-space depth, bukan jarak Euclidean yang menyusutkan hit area di sisi kamera.

Splash sebelumnya dapat selesai sebelum import/renderer siap, dan timer pemuatan dapat menimpa timer exit setelah skip. Kesiapan renderer/fallback sekarang ikut gate loading, timer terpisah, dan skip menghentikan observer/timer pemuatan.

## Batas verifikasi

Browser QA tetap tidak tersedia. Skill Sites menyatakan: “If `$control-browser` is unavailable, skip browser QA: do not start a preview server, install a browser, or improvise another browser-control path.” Tidak dibuat server preview, browser alternatif, atau screenshot V2.3.1.

Tes matriks/physics membuktikan perilaku numerik dan kontrak kode; tidak membuktikan kualitas lighting/material, kemiripan 100% dengan konsep, overflow/browser layout, touch pada perangkat fisik, GPU FPS, context recovery aktual, atau autoplay/audio browser. Semua ini masih perlu QA browser/perangkat. Daftar pemeriksaan ada di `QA_V2_3.md`.

Database Upstash belum terhubung dan respons Nexray live belum terverifikasi. Tidak dilakukan deployment atau perubahan DNS/Search Console. Screenshot yang disertakan berasal dari versi lama dan diberi catatan historical.
