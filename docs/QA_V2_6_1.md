# QA V2.6.1 — 10 Oktober 2026

V2.6.1 mempertahankan visual dan seluruh konten V2.6, lalu memperbaiki dua detail interaksi:

- Hero pendek pada layar tinggi: cover progress berawal dari posisi asli Selected Works. Di awal halaman, progress nol walaupun judul karya sudah terlihat di bawah hero. Pada HP yang heronya panjang, handoff tetap dimulai ketika karya masuk viewport.
- Review rail: posisi pecahan dipelihara terpisah dari nilai scrollLeft yang mungkin dibulatkan browser. Autopan tidak bergantung pada penjumlahan pecahan ke hasil pembulatan setiap frame. Pengukuran lebar tidak lagi dijalankan setiap frame, pembaruan visual sekitar 30 Hz. Pointerup di bagian halaman lain tidak membangunkan rail. Hover hanya berlaku untuk pointer mouse.

Build produksi/TypeScript/prerender berhasil. **49 tes lulus, 0 gagal**; tiga tes tambahan mencakup hero awal pada desktop tinggi, progres komentar pada simulasi pembulatan 30/60/120 Hz, serta pergantian arah di ujung rail. Ini tes numerik, bukan rekaman atau pengukuran FPS browser.

Audit tetap mencatat 18 proyek, 6 journey, 19 tools, 14 orang, 5 komunitas, satu H1, tanpa ID ganda atau aset hilang, 47 SVG valid, serta metadata canonical/OG/robots/sitemap yang konsisten. 106 aset publik V2.5 dan empat API tetap identik; satu perubahan aset lama adalah sitemap yang diminta pengguna. Seluruh aset publik V2.6, profil, dan konten JSON tidak berubah pada patch ini.

JavaScript gzip 91,984 bytes; tidak ada Three.js dalam 30 source files runtime yang terjangkau. Review geometry menggunakan ResizeObserver dan wake events; scene CSS lama tetap disertakan.
